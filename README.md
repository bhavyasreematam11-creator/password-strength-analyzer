# 🔐 Password Strength Analyzer

A Python-based cybersecurity tool that analyzes password strength and provides recommendations for creating stronger passwords.

## 🚀 Features

- Checks password length
- Checks uppercase letters
- Checks lowercase letters
- Checks numbers
- Checks special characters
- Detects common passwords
- Calculates password strength score
- Provides suggestions to improve weak passwords
- Generates secure random passwords
- Uses hidden password input for better privacy
- Provides an easy-to-use menu

## 🛠️ Technologies Used

- Python
- Regular Expressions (`re`)
- `getpass`
- `secrets`
- `string`
